# SQL-FOUNDATIONS-EXERCISES

## 📚 SQL Fundamentals – SELECT & Filtering Exercise

### Project Overview

This project contains my solutions to the **BrightLearn SQL Fundamentals Exercise**, designed to strengthen foundational SQL querying skills. The exercise focuses on retrieving, filtering, sorting, and limiting data from a relational database using a single **employees** table.

The goal was to build confidence in writing clean SQL queries while understanding how different SQL clauses work together to retrieve meaningful information from a database.

---

## Objectives

Throughout this exercise, I practiced writing SQL queries that:

- Retrieve all records and selected columns using `SELECT`
- Remove duplicate values using `DISTINCT`
- Filter records using the `WHERE` clause
- Combine multiple conditions with `AND`, `OR`, `NOT`, and `IN`
- Sort query results using `ORDER BY`
- Limit returned rows using `LIMIT`
- Predict query results before execution to improve SQL logic

---

This exercise demonstrates the use of:
